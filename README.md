# 愛神アプロ公式サイト

HTML・CSS・JavaScriptで構成した静的サイトです。GitHub Pagesでは「Deploy from a branch」を選択し、`main` の `/(root)` を公開します。

YouTubeはメインチャンネルのアップロードプレイリストを埋め込み、動画一覧への直接リンクを併設しています。Xのタイムラインは公式ウィジェットで表示し、アカウントへの直接リンクを常時表示します。

Instagram・BOOTH・FANBOXと仕事用問い合わせ先は準備中です。公式URLが確定したら `index.html` を更新してください。画像素材の権利は各権利者に帰属します。
